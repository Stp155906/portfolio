# Shantalia Portfolio Website

A minimal, parallax-forward React portfolio site for Shantalia, a full stack developer building across iOS, AI systems, data-driven applications, and design-forward products.

## Current Sections

- Hero with positioning statement and GitHub CTA for `stp155906`.
- Project cards for Castella, Veilbound, iOS projects, and NASA JPL internship experience.
- CSS-built placeholder visuals for unfinished projects.
- Experience and about sections that explain the portfolio direction.
- Contact section with an email placeholder.

## Run Locally

From this folder:

```bash
npm run dev
```

Then open the local Vite URL, usually:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```
